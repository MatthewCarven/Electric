2 Installation
--------------
Just copy the file "electric.scr" to your \windows\system (95)
or \windows\system32 (NT) directory and choose "electric" from
the control panel.

3 Configuration
---------------
Electric requires Windows 95 or Windows NT, version 3.51 or more. 

Electric is a computing intensive screen saver.
Although the first version was developped for a 486/66 machine with a 1024*768 display,
the performance will be better with a Pentium and a 640*480 video configuration. 

The animation of the images will only run if your video configuration is set to 256 colors.
With True Color or 16 bit configuration Electric will only display static images.
With a 16 colors configuration, the result will be just terrible. 

Does it mean that you have to drop True Color and high resolution
to change your video setting down to 640*480 pixels with 256 colors ?
The answer is definitely no. Since version 1.2, Electric ! is able
to change automatically the video resolution at startup,
by using Microsoft's DirectX.
You can keep your usual configuration ; all you have to do is to
install Microsoft's DirectX and to check the "Allow DirectX
display mode change" box in Electric!'s settings.
