2 Installation
--------------
Décompressez le fichier electric.zip, copiez le fichier "Electric !.scr"
vers votre repertoire \windows\system (sous Windows 95) ou \windows\system32
(sous Windows NT) et choisissez "Electric !" dans le panneau de configuration. 

3 Configuration
---------------
Electric ! nécessite Windows 95 ou Windows NT, version 3.51 ou supérieure.

Electric ! est un économiseur d'écran assez gourmand en temps de calcul.
Bien que la première version ait été développée pour un 486 avec une
résolution d'écran de 1024*768 pixels, vous obtiendrez de bien meilleures
performances sur un Pentium avec une résolution vidéo de 640*480 pixels. 

L'animation des images ne fonctionnera que si votre carte vidéo et configurée
en 256 couleurs. Avec une configuration en "True Color" ou de 16 bits Electric !
se contentera d'afficher des images statiques.
Avec une résolution de 16 couleurs, le résultat sera assez nul... 

Cela signifie-t'il que vous devez abandonner les hautes résolutions
et reconfigurer votre PC pour tourner en 640*480 pixels avec 256 couleurs ?
La réponse est non. Depuis la version 1.2, Electric ! est capable de changer
automatiquement la résolution vidéo quand il se lance, en utilisant DirectX de Microsoft.
Vous pouvez garder votre configuration habituelle. Tout ce que vous avez à faire
est d'installer DirectX sur votre PC et de cocher l'option
"Allow DirectX display mode change" dans la configuration d'Electric !.

5 Quoi de neuf dans la version 1.3 ?
------------------------------------
* Optimisé : le temps de calcul d'une nouvelle image est beaucoup plus court,
à condition que l'option DirectX soit utilisée. 
* Ajouté : Electric peut maintenant afficher une ligne de texte "subliminal".
Bon, ce n'est pas si subliminal que ça, mais vous pouvez essayer quand même. 
* Ajouté : Effets de dallage et de brouillage. 
* Ajouté : Nouvelles palettes de couleur. 
* Corrigé : L'option DirectX fonctionne correctement avec Windows NT 4.0.
* Corrigé : L'alimentation minimale et la désactivation de l'écran fonctionnent
désormais même quand l'option DirectX est cochée.

que l'option DirectX est activée.
