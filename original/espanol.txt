2 Instalación
--------------
Copia el fichero "electric.scr" en el directorio \windows\system
(Win 95) o en \windows\system32 (Win NT) y selecciona "electric"
desde el panel de control.

3 Configuración.
---------------
Electric! requiere Windows 95 o Windows NT, versión 3.51 o posterior.

Electric! es un protector de pantalla que requiere gran capacidad de proceso.
Aunque la primera versión se desarrolló para un PC 486/66 con display de 1024*768,
el rendimiento será mejor con un Pentium y configuración de vídeo 640*480.

Las imágenes solo se verán en movimiento si tu configuración de vídeo es de 256 colores.
Con True Color o 16 bits, Electric! sólo mostrará imágenes estáticas. Con una
configuración de 16 colores, el resultado será simplemente terrible.

¿Significa eso que tienes que abandonar True Color e imágenes de alta resolución
para cambiar tu configuración de vídeo a 640*480 pixels con 256 colores? ¡NO!

A partir de su versión 1.2, Electric! es capaz de cambiar de forma automática
tu configuración de vídeo utilizando Microsoft DirectX. Puedes conservar tu configuración
actual. Lo único que tienes que hacer es instalar Microsoft DirectX y seleccionar la opción
"Allow DirectX display mode change" durante la configuración de Electric!.

5 Novedades en la versión 1.3
------------------------------

* Optimizado: El tiempo necesario para calcular una nueva imagen es mucho menor
cuando se utiliza DirectX.
* Nuevo: Electric! puede presentar una línea de texto "subliminal". Bueno, no es
realmente subliminal, pero te puedes hacer una idea.
* Nuevo: Efectos de cascada y difuminado.
* Nuevo: Más paletas de colores.
* Solucionado: La opción DirectX ya trabaja con Win NT 4.0
* Solucionado: El modo ahorro del monitor ahora funciona cuando se usa DirectX.
* Solucionado: El protector de pantalla no se detiene cuando aparece una ventana
"Pop Up" en modo DirectX.

6 Novedades en la versión 1.2
------------------------------

* Nuevo: Cambio del modo vídeo con DirectX para Win 95
* Nuevo: Posibilidad de cambiar la velocidad de animación.
* Nuevo: Posibilidad de seleccionar paleta de colores.
* Nuevo: Demo en pantalla completa con posibilidad de cambiar la configuración "on line"
* Solucionado: La opción "screen scan" del anti virus McAfee detiene el protector de pantalla.

7 Novedades en la versión 1.1
------------------------------

* Nuevo: Posibilidad de configuración con una ventana de demo, para que puedas ver cómo
serán las imágenes.

   1.- Aumento de la velocidad cuando el "Multimedia Player" está activo.
